Project overview

The research

Purpose and intended applications of the project.

01 / Objective

Project objective

Project Genesis aims to copy a powerful Quirk, modify the copy, and give it to another person, whether or not they already possess a Quirk. The project also explores modifying an existing Quirk.

02 / Application

Intended applications

A transferred Quirk could give a Quirkless person an ability or allow someone with a Quirk to possess multiple abilities. Modifications could also change a person's existing Quirk.
